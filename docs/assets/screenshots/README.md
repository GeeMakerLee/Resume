# 项目截图

这里存放准备公开给 HR 的真实截图。当前没有截图；页面不会显示空白占位图。

## Story2Game

1. 将真实截图命名为 `story2game-ui.png`，放入本目录。
2. 打开 `docs/media.js`，取消 `story2game` 数组里示例对象的注释。
3. 保存并提交；无需安装依赖或重建网页。
4. 如果也希望显示在 GitHub 主页，在根目录 `README.md` 的 Story2Game 节追加：

```md
![Story2Game 游戏生成与运行界面](docs/assets/screenshots/story2game-ui.png)
```

建议选取能展示“故事输入 → 生成结果 → 实际运行”的完整画面。宽度约 1400–1800 像素，使用 PNG 或 WebP。上传前去掉 API key、邮箱、聊天记录和其他私人信息。

## 其他项目

在 `docs/media.js` 的对应数组加入相同格式的对象。`src` 相对于 `docs/index.html`，可同时添加多张截图。为每张图写出 `zh` 和 `en` 图注。
